# Тестовое задание

Небольшой каталог онлайн-курсов, сверстанный по макету из Figma. Приложение включает адаптивную сетку карточек, поиск по названию, фильтрацию по категориям и кнопку дозагрузки карточек.
Демо: [https://test-task-course.netlify.app/](https://test-task-course.netlify.app/)

## Как запустить

1. Установить зависимости:

```bash
npm install
```

2. Запустить локальную сборку sass:

```bash
npm run dev
```

3. Использовать локальный сервер (можно через расширение Live Server)

## Структура проекта

```text
src/
├── assets/
│   ├── fonts/         # Локальные шрифты
│   └── images/        # Изображения карточек и декоративные элементы
├── data/
│   └── courses.json   # Данные каталога курсов
├── js/
│   ├── api.js         # Загрузка данных
│   ├── filters.js     # Делегирование событий фильтров
│   ├── main.js        # Инициализация приложения
│   ├── render.js      # Отрисовка карточек и фильтров
│   ├── search.js      # Поиск и debounce
│   └── state.js       # Глобальное состояние блока
├── scss/
│   ├── base/          # Сброс, переменные, шрифты, глобальные стили
│   ├── blocks/        # BEM-блоки интерфейса
│   └── style.scss     # Главная точка сборки стилей
├── index.html         # Основная HTML-страница
├── style.css          # Скомпилированный CSS
└── style.css.map      # Source map для CSS
```

## Реализовано

- Pixel-perfect верстка блока каталога по макету
- Адаптивный интерфейс с резиновым масштабированием
- Сетка карточек на CSS Grid
- Поиск по названию курса без перезагрузки страницы
- Фильтрация по категориям с пересчетом количества карточек
- Data-driven подход с загрузкой данных из `courses.json`
- Использование `fetch` и обработка ошибок через `try/catch`
- Хранение состояния приложения в объекте `state`
- Делегирование событий для блока фильтров
- Debounce для поля поиска
- Рендер карточек и фильтров через `<template>`
- Кнопка `Load more` с поэтапной подгрузкой карточек
- `loading="lazy"` для изображений карточек
- Разделение логики по небольшим JS-модулям
- SCSS-структура по BEM
